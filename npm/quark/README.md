# @quark-client/quark

A local-first, keyboard-driven HTTP client.

## Installation

```bash
npm install -g @quark-client/quark
```

Or use with `npx`:

```bash
npx @quark-client/quark
```

## Usage

```bash
quark
```

For more information, visit [github.com/crazy-vedic/Quark](https://github.com/crazy-vedic/Quark).
